## Key Features Covered

### Azure Services
- **Compute**: Virtual Machines, VMSS, Container Instances, App Services
- **Networking**: VNet, Load Balancer, Application Gateway, NSG, Azure Bastion, VNet Peering
- **Storage**: Storage Accounts, Blob Storage, File Shares, Managed Disks
- **Database**: Azure SQL Database, SQL Server management
- **Security**: Key Vault, RBAC, Network Security Groups, Identity Management
- **Monitoring**: Azure Monitor, Log Analytics, Azure Backup, Site Recovery
- **Infrastructure as Code**: ARM Templates, Bicep DSL
- **Data Services**: Azure Data Factory, Data Lake Storage Gen2

### DataDog Capabilities
- Agent installation and configuration
- Infrastructure monitoring and alerting
- Application performance monitoring (APM)
- Log management and analysis
- Custom metrics and dashboards
- Alerting and notification systems

### Linux Administration
- **Command Line Mastery**: File operations, text processing, pattern matching
- **Advanced Operations**: sed/awk processing, archive management
- **Shell Scripting**: Variables, loops, functions, automation
- **Package Management**: Software installation and maintenance
- **System Administration**: Process management, network troubleshooting

### Container Technologies
- **Docker**: Installation, container management, Docker Compose
- **Kubernetes**: Cluster setup (Minikube, kubeadm, AKS, EKS)
- **Container Orchestration**: Workload deployment, services, scaling
- **Advanced K8s**: ConfigMaps, Secrets, Networking, Security, Helm

### Service Management
- **ITIL Framework**: Service lifecycle management
- **Modern ITSM**: Integration with SRE and DevOps practices
- **Process Implementation**: Incident, Problem, Change Management

### Database Management
- **Azure SQL**: Database creation, management, optimization
- **Security**: Authentication, authorization, threat protection
- **Performance**: Monitoring, tuning, scaling strategies
- **Backup & Recovery**: Point-in-time restore, disaster recovery

## Training Objectives

1. **Azure Administrator Certification (AZ-104)** preparation with comprehensive hands-on labs
2. **Cloud Infrastructure Management** using Azure services and best practices
3. **DataDog Monitoring Platform** implementation for observability and alerting
4. **Linux System Administration** for cloud and on-premises environments
5. **Container Technologies** mastery with Docker and Kubernetes
6. **Database Management** using Azure SQL and related services
7. **Data Engineering** with Azure Data Factory and ETL processes
8. **Service Management** following ITIL framework and modern practices
9. **Infrastructure as Code** using ARM Templates and Bicep
10. **Security Implementation** across all technology stacks

## Prerequisites

- **Azure Subscription**: Active Microsoft Azure account with contributor access
- **Development Environment**: Linux/Windows/macOS with terminal access
- **Tools**: Azure CLI, PowerShell, Docker, kubectl installed
- **DataDog Account**: For monitoring and observability tasks
- **Basic Knowledge**: Cloud computing concepts, networking fundamentals
- **Text Editor**: VS Code or similar for configuration files
- **SSH Keys**: For secure VM access and authentication
